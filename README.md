# 텅장 디펜스 · 탕이와 텅이의 작은 집

청년의 주거·교통비를 계산하고, 지갑 수호자와 생활을 점검하며 방을 꾸미는 웹 서비스입니다. 2026 고려대학교 정보대학 NewbieThon 제출용 구현입니다.

- 주거·교통 진단을 첫 화면에 배치했습니다.
- 탕이(남성형)·텅이(여성형), 기본/고민/기쁨/낮잠 포즈와 다양한 CSS 반응을 제공합니다.
- 50 GP / 100 GP에서 조끼·가방 / 월계관·긴 망토로 외형이 진화합니다. 진화 단계는 각 1개 기본 그림에 CSS 동작을 적용합니다.
- 여섯 소품의 고정 위치 배치·보관, 낮/노을/밤, 위치 이동, 대화·춤·낮잠·가위바위보·가구 사용이 가능합니다.
- 이메일 회원가입·로그인, 회원별 SQLite 저장, 소비 CRUD, 주간 점검, 수령 혜택 기록을 지원합니다.
- 서버가 금액을 계산하고 OpenAI Responses API가 그 결과를 설명합니다. API 키가 없어도 계산 기능은 작동합니다.

## 빠른 실행

Node.js **24**를 설치하고 이 폴더에서 실행하세요. 외부 npm 런타임 패키지를 사용하지 않아 `npm install`은 필요 없습니다.

```bash
cp .env.example .env
npm test
npm start
```

Windows PowerShell에서는 `Copy-Item .env.example .env`를 사용합니다. 브라우저에서 `http://localhost:3000`을 열어 회원가입하세요. `.env`의 `APP_ORIGIN`도 같은 주소여야 합니다. HTML을 더블클릭하는 방식은 지원하지 않습니다.

`샘플로 먼저 둘러보기`는 임시 체험이며 새로고침하면 사라집니다. 실제 계정으로 로그인한 기록은 `data/teong.sqlite`에 저장됩니다. 이 파일이나 `.env`는 공개 저장소에 올리지 마세요.

## GitHub 업로드와 실제 배포

자세한 화면 순서는 [DEPLOY.md](DEPLOY.md)를 보세요. GitHub는 코드를 보관하고, 서버는 Render Web Service에서 실행합니다. **GitHub Pages는 이 앱의 로그인·DB·LLM 서버를 실행할 수 없습니다.**

1. ZIP 압축을 풀어 GitHub Public Repository에 폴더 내부 파일을 업로드합니다. 루트에서 `package.json`이 보여야 합니다.
2. Render에서 GitHub 저장소를 연결한 Docker Web Service를 만듭니다.
3. `APP_ORIGIN=https://실제서비스주소.onrender.com`, `NODE_ENV=production`, `DATA_DIR=/app/data`를 설정합니다.
4. `/app/data`에 영구 디스크를 연결합니다. Render 영구 디스크는 유료입니다. 디스크 없는 배포는 재시작·배포 시 가입 정보가 사라질 수 있습니다.
5. AI를 쓰려면 서버 환경변수에 `OPENAI_API_KEY`와 이용 가능한 `OPENAI_MODEL`을 설정합니다. 기본 모델은 `gpt-4.1-mini`입니다.

## 계산 범위와 근거

확인일 **2026-09-12**. 전체 대한민국 정책을 포괄하지 않는 제한된 시뮬레이션입니다.

| 항목 | 구현 범위 |
|---|---|
| K-패스 기본형 | 서울 만 19~34세 일반 청년, 2026년 9월, 월 15~60회·20만원 이하, 하루 2회 이하 |
| 모두의 카드 일반형 | 위 조건 + 모든 승차 운임 3,000원 미만. 9월 한시 기준금액 25,000원 |
| 모두의 카드 플러스형 | 3,000원 이상 운임 포함 시 45,000원 기준으로 기본형과 비교. 혼합 이용의 일반형 세부 최적화는 제외 |
| 서울시 청년월세지원 | 2026년 기본 공고의 출생연도·주거·소득·재산 등 자가진단. 5월 19일 접수 종료 |

기본형 예상 환급은 `(월 교통비 − 시차 이용금액) × 30% + 시차 이용금액 × 60%`입니다. 모두의 카드와 합산하지 않고 더 큰 금액 하나를 사용합니다. 실제 지급액은 승인된 승차 내역에 따라 달라집니다. 60회 초과·20만원 초과 및 다른 우대유형은 계산을 보류합니다. 10월 이후 실제 이용금액에는 9월 한시 기준을 적용하면 안 됩니다.

주거는 기본 조건을 모두 입력했을 때 `min(월세, 200000원) × 최대 12개월`의 **선정 가정 금액**을 보여줍니다. 관리비를 제외하며 마감된 모집이므로 현재 예상 절약 합계에는 넣지 않습니다. 소득은 본인 월급만이 아닌 공고상 건강보험 가구 기준입니다. 최종 심사, 군복무 연령 예외, 건강보험료 환산과 상세 가구 판정은 기관 안내로 확인해야 합니다.

- [신한카드 K-패스·모두의 카드 공식 안내](https://www.shinhancard.com/pconts/html/card/micro/k_pass_micro.html)

## 구조

- `public/`: 프런트엔드, CSS, 캐릭터·방 이미지
- `server.mjs`: HTTP 서버, 계정·세션, SQLite, LLM 프록시
- `calculations.mjs`: 서버 계산의 기준 원본
- `public/calculations.js`: 샘플 모드용 동일 계산 사본. 계산 수정 시 두 파일을 함께 갱신하세요.
- `test/`: 계산 경계·계정 격리·저장/재시작·AI 대체 응답 테스트
- `.github/workflows/test.yml`: push/PR 자동 테스트

API: `POST /api/signup`, `/api/login`, `/api/logout`, `/api/diagnose`, `/api/chat`; `GET/PUT/DELETE /api/account`.

## 구현 및 검증 상태

자동 테스트 6개 통과: 계산 경계값과 금액 분리, 계정 간 격리, 재로그인, 재시작 복원, Origin 검사, 저장 충돌, API 키 없는 대체 응답. 브라우저에서 샘플 진단·대화 UI·방 전환을 확인했습니다.

LLM 실서버 응답은 API 키 설정 전이므로 미검증입니다. 서버에 키를 넣고 로그인한 뒤 질문 폼의 'AI 설명 사용'을 선택하세요. 실패하면 모드를 명시하고 계산 안내로 돌아갑니다. LLM 문구는 금액 원장에 반영하지 않으며, 표의 코드 계산 결과가 기준입니다.

이메일 소유 확인·비밀번호 재설정·다중 인스턴스 운영·관리자 도구는 제외했습니다. 비밀번호는 scrypt 해시로 저장합니다. 세션은 HttpOnly 쿠키이며 운영에서는 Secure가 적용됩니다. API는 동일 출처 검사와 회원별 접근 제한, 저장 버전 충돌 검사를 합니다. GP·보상은 외부 경제적 가치가 없는 데모 상태이며 부정행위 방지 서버 원장은 미구현입니다. 실제 서비스 전에는 이메일 인증, 개인정보 처리 정책, 운영 백업, 남용 방지를 보강해야 합니다.
